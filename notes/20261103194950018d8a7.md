NSEvent otherEventWithType: returns an autoreleased object. The daemon thread is plain Rust with no NSAutoreleasePool, so without objc_autoreleasePoolPush/Pop around the call every media-key press leaked an NSEvent. The NSEvent class and selectors are resolved once into a OnceLock (stored as usize because raw pointers are not Sync). Any new Objective-C call that returns autoreleased objects off the main thread needs the same wrapping.
