On macOS, holding a Command (Meta) key and releasing another key simultaneously often causes the OS to suppress the key up event for the secondary key. This leads to keys/layers (like space-anchored or alpha-anchored layers) getting stuck in the active state inside keydo. To fix this, we integrated CGEventSourceKeyState into the keyboard event loop. Whenever any event or modifier change triggers, we query the hardware state of currently pressed keys stored in Keyboard active cache. If a key is physically released but registered as pressed in the daemon, we synthesize a key release event, cleanly deactivating the stuck layer.
