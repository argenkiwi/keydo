keydo's root Cargo.toml on main now declares an explicit [lib] target (src/lib.rs) exposing only the platform-agnostic modules (config, config_impl, config_parse, config_validate, error, ini, keyboard_impl, keyboard_types, keys, macro_parse, macro_types, unicode). This was added so the separate keydo-playground repo's keydo-wasm crate can depend on keydo via a git rev-pinned dependency and compile it to wasm32-unknown-unknown, instead of a relative path dependency inside a shared workspace.

Before this, the [lib] target only existed on an unmerged prototype branch called playground (which also contained the playground/ web app itself). That branch has been deleted: playground/ was extracted with history preserved into github.com/argenkiwi/keydo-playground, and the [lib] target was ported to main as its own minimal, additive commit. Nothing on main outside Cargo.toml/src/lib.rs changed as part of this.
